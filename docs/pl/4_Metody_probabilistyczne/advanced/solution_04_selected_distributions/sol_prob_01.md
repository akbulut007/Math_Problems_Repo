# 🎲 Problem 1 — Coin × Coin

## 🧪 Sample Space

The experiment consists of two coin tosses:

| Outcome | Description        |
|--------|--------------------|
| (H,H)  | Head, Head         |
| (H,T)  | Head, Tail         |
| (T,H)  | Tail, Head         |
| (T,T)  | Tail, Tail         |

---

## 📌 Part A — Events

### 1. Exactly one head

| Outcomes |
|----------|
| (H,T)    |
| (T,H)    |

---

### 2. Both tosses are the same

| Outcomes |
|----------|
| (H,H)    |
| (T,T)    |

---

### 3. At least one head

| Outcomes |
|----------|
| (H,H)    |
| (H,T)    |
| (T,H)    |

---

### 4. The first toss is tails

| Outcomes |
|----------|
| (T,H)    |
| (T,T)    |

---

### 5. The second toss is heads

| Outcomes |
|----------|
| (H,H)    |
| (T,H)    |

---

## 🧠 Part B — Interpretation

### Case 1

| Outcomes |
|----------|
| (H,H)    |
| (H,T)    |

**Interpretation:**  
👉 The first toss is heads.

---

### Case 2

| Outcomes |
|----------|
| (H,T)    |
| (T,H)    |

**Interpretation:**  
👉 Exactly one head occurs.

---

## ✅ Final Summary

| Event Description            | Outcomes                        |
|-----------------------------|--------------------------------|
| Exactly one head            | (H,T), (T,H)                   |
| Both same                   | (H,H), (T,T)                   |
| At least one head           | (H,H), (H,T), (T,H)            |
| First toss is tails         | (T,H), (T,T)                   |
| Second toss is heads        | (H,H), (T,H)                   |
